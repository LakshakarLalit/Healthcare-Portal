# Healthcare-Portal

The Healthcare Portal is a web-based application developed using **HTML, CSS, JavaScript, Python, Django, and SQL** that helps manage healthcare services digitally and efficiently. The system provides features such as user registration and login, doctor management, appointment booking with time slots, patient record management, and an admin panel for monitoring all portal activities. Patients can search doctors by specialization, book appointments online, and check their appointment status, while doctors can manage their schedules and appointments easily. The frontend is designed using HTML, CSS, and JavaScript to create a responsive and user-friendly interface, and the backend is powered by Django and Python with SQL database connectivity for secure data storage and management. This project reduces manual work, saves time, and improves the overall healthcare management process through a secure and organized digital platform.
